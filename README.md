# ors-socials

Published image assets for [ORS Leverage](https://orsleverage.com) social posts.

Each day's cards are rendered locally and committed here so that Buffer has a stable,
permanent URL to fetch from when a post publishes. Files are organised by publish date:

```
2026-08-05/post-1.png
2026-08-05/post-2.png
2026-08-05/post-3.png
```

Served over GitHub Pages:

```
https://orssolutionsinc-rgb.github.io/ors-socials/2026-08-05/post-1.png
```

## Notes

- This repo is public because Buffer must fetch the images without credentials. Everything
  here is published to LinkedIn, Instagram and Facebook anyway.
- Images are 1080 x 1350 at 2x (2160 x 2700), roughly 200KB each, 3 per day.
- Anything older than 90 days is pruned. The social platforms hold their own copies once a
  post has published, so the retention here is a convenience archive, not a dependency.
